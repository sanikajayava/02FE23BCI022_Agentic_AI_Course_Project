# Project data

The source bundle includes these question-bank files:

- `question_bank.json`
- `real_question_bank.json`

It also includes lesson plans under `lesson_plans/` for Cloud Computing,
Cyber Security, Deep Learning, and Gen AI.

The historical-paper archive under `Question_Papers/<subject>/<exam_type>/`
is not included. Add it only if you have permission to share those papers.

The application creates `faculty_users.db` here on first use; do not commit
that database.
